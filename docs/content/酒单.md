# 示例酒单：16 杯（+ 迷情剂 + 2 隐藏 = 19）

**选取原则**：轴要撑开、味要撑开、度数要撑开、留几杯当教具。
轴值是**示例角色**的反应曲线，换角色要重写（见 README「引擎 / 内容包」）。

记号：`杯` = 标准杯数（实际由 ABV 从配方算，此处为参考值）

---

## 一、纯饮 / 基酒（6）

### 1. 威士忌 · 1.0 杯
`守门 ++ · 唤醒 − · 亲近 +`　口味：烈+4 苦+2 香+4（泥煤·海盐·烧过的绳子）
**「越喝越端着」那条曲线的标准样本。** 不兑东西时下去慢，酒味重到没法边说话边喝，一口一停。
**关键：它不是没话，是把话收起来了。**

### 2. 龙舌兰 · 1.0 杯
`唤醒 ++ · 愉悦 + · 守门 −− · 精度 −`　口味：烈+5 酸+1 香+2（青草·胡椒）
子弹杯一口闷，从入口到结束不到两秒，**没有停顿的余地**。
**坏事不是喝醉，是喝完之后听见了自己真的怎么想。**

### 3. 伏特加 · 1.0 杯 ⭐教具
`愉悦 0 · 唤醒 + · 精度 −−`　口味：烈+5，**其余接近 0**
**没有味道的酒。**
**教学价值：它证明口味和效果是两条独立的线。** 尝不出任何东西，照样把你放倒。

### 4. 黑朗姆 · 1.0 杯
`愉悦 + · 亲近 + · 守门 −`　口味：烈+4 甜+3 香+3（糖蜜·橡木·香草）
甜得很粗糙，不精致但坦荡。**讲故事的酒。**

### 5. 金酒 · 1.0 杯
`唤醒 + · 精度 −`　口味：烈+4 香+4（杜松子·柑橘皮·草本）苦+1
干、清冷。**很多调和酒的骨架**，单饮少见但成立。

### 6. 清酒 · 0.7 杯
`亲近 ++ · 守门 − · 唤醒 −`　口味：烈+2 甜+2 香+3（米·瓜果）
温着喝，不加冰。**上头慢，适合长夜。** 聊天的酒。

## 二、低度 / 非蒸馏（3）

### 7. 啤酒 · 0.5 杯
`愉悦 + · 唤醒 −`　口味：烈+1 苦+2 香+2（麦芽·酒花）质地：气泡高
**「轻松一下」就是它的全部意义。**

### 8. 红葡萄酒 · 0.9 杯
`愉悦 + · 亲近 + · 精度 −`　口味：烈+3 酸+2 **涩+3** 香+4（浆果·橡木）
**涩是它的签名**——那条最慢上来、最慢散掉的轴。慢的酒。

### 9. 苦艾酒 · 1.5 杯 ⭐教具
`（效果栏写传说，实际配方里没有那个东西）`　口味：烈+5 苦+3 香+5（茴香·药草）
**它的迷幻是假的。** 19 世纪整个欧洲相信它让人发疯、看见绿仙子，因此禁了近百年。
真相：被指控的成分含量低到不可能起作用；真正让人出事的是**接近 70% 的度数**。
**教学价值：唯一一杯「效果栏写着传说、配方里什么都没有」的真酒。**

## 三、经典调和（5）

### 10. 马天尼 · 1.4 杯 ⭐教具
`守门 + · 唤醒 + · 精度 −`　口味：烈+5 香+3（杜松·柠檬皮）甜+0.5
金酒 + 干味美思 + 搅拌 + 柠檬皮或橄榄。
**教学价值：结构匹配的样本。** 比例 2:1 到 15:1 都还叫马天尼；**换掉味美思就是另一杯酒。**

### 11. 尼格罗尼 · 1.2 杯
`愉悦 − · 唤醒 + · 守门 −`　口味：烈+3 甜+2 酸+0.5 **苦+4（主导）** 香+4
金酒 + 金巴利 + 甜味美思，1:1:1。
**苦停留得极长，长到你想再喝一口把它盖掉——而那正是它要你做的。**

### 12. 金汤力 · 0.8 杯
`唤醒 + · 愉悦 −`（精度只由酒精下降，汤力水不能把它推正）　口味：烈+2 苦+3 酸+1 香+3 质地：气泡高
**汤力水本来是药**——奎宁治疟疾，苦得没法喝，兑金酒才咽得下去。
**底色不是回忆，是药。喝它的人在维持功能，不是在享受。**

### 13. 玛格丽特 · 1.3 杯
`唤醒 ++ · 愉悦 +`　口味：烈+4 **酸+4** 甜+2 香+2 质地：盐边
酸把人拽得清醒一点，但度数不低。**清醒和失控同时进行。**

### 14. 长岛冰茶 · 2.5 杯 ⭐教具
`唤醒 + · 精度 −−`　口味：烈+4 甜+3 酸+3 香**（归并到根）**
五种基酒兑可乐。**缝合怪。**
**教学价值：离散度样本。** 香在风味轮上没有共同的具体祖先，只能报到根。
**建议在示例包里标为「管制品」**——点它需要说明动机。

## 四、特殊（2）

### 15. Espresso Martini · 1.0 杯 ⭐教具
`唤醒 ++ · 愉悦 +`（精度由酒精单独决定，只降）　口味：烈+3 苦+4 甜+2 香+5（咖啡）
伏特加 + 咖啡利口酒 + 现萃浓缩，冰摇后滤净，杯口三粒咖啡豆。
含 **1.33 份咖啡因**（非酒精活性成分，§3.2a）：
30 ml 浓缩 = 1.0，20 ml 咖啡利口酒 = 20/30 × 0.5 = 0.33。
*（v11b 更正：此处原写「2 份」，与原料表对不上。）*
**教学价值：唯一一杯「越喝越精神又越糊涂」的矛盾体。**
咖啡因把**唤醒**顶上去，酒精把**精度**拽下来——**证明唤醒和精度可以背离。**
**注意它没有 +精度**：咖啡不解酒，精度是六轴里唯一骗不了的一条。
深夜的酒。副作用：喝完更睡不着。

### 16. 白开水 · 0 杯
`（无）`　口味：全 0
描述：**「一杯水。」**

## 不计入这 16 杯的

- **迷情剂** · 0 杯 —— 配方与白开水完全相同，只有名字和效果栏不同。
  **两条并排放在酒单上，谁看一眼都懂了整个系统。**
- **隐藏 1「五彩斑斓的黑」** —— 离散度拉满 → 宕机
- **隐藏 2「heaven」** —— 全是高度酒且只有高度酒 → 塌 / 吐
