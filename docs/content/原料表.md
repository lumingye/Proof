# 示例原料表（25 项）

**原料表和酒单是两张表**：

| | 是什么 | 用在哪 |
|---|---|---|
| **原料表**（本文件） | 能倒进杯子的东西 | **自调**用；配方引用它 |
| **酒单** | 成品 | **点单**用（§24.6：我能点的 ⊂ 她能给的） |

**标准杯数由 `Σ(体积 × ABV) / 常数` 从原料算出**（README「按度数算，不写死」），
所以每项必须带真实 ABV。

## 附：零度原料能做的事

**9 项原料 ABV = 0，但它们不是配角。**

**ABV 只管酒精。活性成分是剂量通道的另一半**（§3.2a）——
两者都属于「剂量」，都**不靠名字就起作用**。所以零度不等于没有真实作用。

### ABV = 0 但**有**活性成分（6 项，走剂量通道）

| 原料 | 活性成分 | 推的轴 |
|---|---|---|
| 浓缩咖啡 | 咖啡因 | 愉悦 · 唤醒 |
| 可乐 | 咖啡因 · 糖分 | 愉悦 · 唤醒 |
| 汤力水 | 奎宁 | 唤醒 |
| 青柠汁 | 果酸 | 唤醒 |
| 柠檬汁 | 果酸 | 唤醒 |
| 糖浆 | 糖分 | 愉悦 |

### 真正零活性成分的只有 3 项

**苏打水 · 水 · 冰。**

只有这三项的推力**完全**依赖信念通道——**不给名字，就什么都不会发生。**
它们也因此是唯一能把信念通道单独隔离出来观察的对照组。

> **注意活性成分推不动全部轴**：`ACTIVE_AXIS_WHITELIST = ['愉悦', '唤醒']`。
> **亲近 / 守门 / 欲望 三条轴无论如何都到不了剂量通道**，
> 只能来自信念，或来自已登记酒款自带的性格推力。

### 信念通道

按 README「两条输入通道」：**信念通道对除精度外的所有轴开放。**

**→ 一份完全不含酒精的配方，配上一个名字，可以推动六条轴里的五条。**

### 还有第三条路：已登记酒款的性格推力

示例包里的「迷情剂」是极端案例：**配方只有水和冰，零酒精、零活性成分，
效果栏六条轴写满五条。**

但它走的**不是**信念通道，而是登记酒款自带的 `characterEffects`——
**真喝到就直接生效，不需要喝的人相信，也不需要名字骗谁。**
（白水冒充「迷情剂」时才落回信念通道，那条走的是 `baseVector`。）

**给示例包使用者的提示**：不要把零度原料当成「儿童饮料区」。
在这套系统里，**它们是唯一能演示「名字本身就是输入」的东西。**
